## 常见问题

**转换后的文件保存在哪？**

转换完成后生成下载链接，自行下载到本地。服务器不会将用户文件用于其他用途。

**手机上能用吗？**

可以。手机浏览器访问官网即可，也可以用微信公众号"极闪PDF"或微信小程序，三端账号通用、会员共享。

**扫描版 PDF 能转成可编辑的 Word 吗？**

能。普通 PDF 转 Word 走常规通道；纯图片型的 PDF（扫描件）请用[图片PDF转Word](https://www.wdangz.com/pdf-to-word2)，会走 OCR 识别通道重新提取文字。

**为什么选择在线工具而不是桌面软件？**

不占磁盘空间、不用更新、换电脑也能用。对于转换这种低频刚需，网页工具的开箱即用体验优于安装一个几百 MB 的软件。
